### Task 1: Skills and prompts

**Interfaces:** Skill `kicad-footprints` (front matter `name: kicad-footprints`,
description "Read, check, create, render, approve and delete footprints; library order;
no invented dimensions."). Sections (spec §13.2, binding content):
1. **Library rule**: stock → manufacturer → third-party → handmade (`fp_create`) last;
   any origin is checked with `fp_check(expected=…)` against the datasheet land pattern
   before use; differences are reported, never used silently.
2. **No invented dimensions**: every `fp_create` number from the cited source (recommended
   land pattern over package drawing); documented defaults (courtyard margin 0.25 mm) are
   named in the approval message; no land pattern → ask the user.
3. **Procedure**: `parts_get_notes` → land pattern → `fp_create` with `symbol` →
   `fp_render` → present (render, every `fp_check` warning, source document + location,
   key dimensions **measured from the read-back**, the question "Approve this
   footprint?") and **stop the turn** → `fp_approve` only in a later turn after an
   explicit ok, quoting the user's words → `sch_set_fields`.
4. **Checking existing footprints** (J402/U202): `fp_check` with `symbol` and `expected`;
   explain unmatched shell/mounting pads (`allow_unmatched_pads`).
5. **Memory and time**: the first footprint tool may take a few seconds
   (`footprint_libraries_loaded`).
6. **Errors**: one line per FP-C9 code with what to do (e.g. `library_conflict` → tell the
   user which row to rename; `approval_not_allowed` → ask the user to look at the render
   and confirm again).

`kicad-schematic-editing`: replace "creating library symbols or footprints is not
something you can do" with "creating footprints: see the `kicad-footprints` skill;
symbols cannot be created"; explain notes `footprint_needs_review`,
`footprint_review_unknown`, `footprint_libraries_loaded`; update the `footprint_unverified`
wording. `part-notes`: rule 10 allows `<repo-nick>:<name>`; new optional section
`## Land pattern` (table `| Pad | X (mm) | Y (mm) | W (mm) | H (mm) | Drill (mm) |` + courtyard
+ body, each row cited `[D1 p.N]`); `REQUIRED_SECTIONS` unchanged. Research prompt: fill
`## Land pattern` when there is no exact stock match. `copperchat-tools` and
`session-schematic`: list the seven `fp_*` tools (writes only in Schematic/Free).
